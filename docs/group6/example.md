# Markdown 格式示例

这是一个用于校验 Markdown 渲染器的示例文件，涵盖了常用语法。

## 1. 标题

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

## 2. 文本样式

**粗体文本**  
*斜体文本*  
***粗斜体文本***  
~~删除线文本~~  
`行内代码`  
普通文本  
<u>下划线（HTML）</u>  
H~2~O（下标，部分渲染器支持）  
X^2^（上标，部分渲染器支持）

## 4. 列表

### 无序列表

- 项目一
- 项目二
  - 子项目 A
  - 子项目 B
- 项目三

### 有序列表

1. 第一项
2. 第二项
   1. 子项 2.1
   2. 子项 2.2
3. 第三项

### 任务列表

- [x] 已完成任务
- [ ] 未完成任务
- [ ] 另一个未完成任务
